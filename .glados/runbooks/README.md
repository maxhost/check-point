# Runbooks

Operational procedures that already exist in the repository. This file points to them; the
linked files are authoritative.

| Task                                   | Authoritative source                                                                                                                  | Notes                                                                                                                                                                                                                                                                     |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Run Neon integration suites            | `tools/neon-test.sh` (header)                                                                                                         | `bash tools/neon-test.sh [file]`, `--app consumer`, `--related <files>`. Needs `apps/merchant/.env.local` with `NEON_CI_DATABASE_URL`, `NEON_CI_DATABASE_URL_UNPOOLED`, `NEON_CI_CONSUMER_DATABASE_URL`. Aborts if the CI branch host equals `DATABASE_URL` (production). |

Applying to production is a deliberate, owner-visible step.                                                                                                                                                               |
| Usable worktree                        | `tools/worktree-new.sh`                                                                                                               | Installs its own `node_modules` offline. Never symlink `node_modules`.                                                                                                                                                                                                    |

Scoped to those merchants by design.                                                                                                                                                   |
