# Repositorio remoto

Repositorio canónico de CheckPass Club:

- https://github.com/maxhost/check-point.git

## Política de publicación acordada

- La rama principal es `main`.
- Los cambios de este proyecto se documentan, se verifican y se publican mediante commits
  intencionales a `main`, según autorización explícita del fundador.
- Antes de cada commit se inspecciona el estado para no incluir archivos ajenos al alcance.
- El remoto se denomina `origin` y debe apuntar exclusivamente a la URL canónica anterior.

## Estado inicial

El primer commit publicará la documentación de descubrimiento, producto, arquitectura,
ADRs, specs y proceso. El scaffold de código espera que la Spec 0010 pase de `borrador` a
`cerrada`.
