No inferir coste cero de caché ni ausencia de trabajo por bytes desconocidos. `CPU_TRACE:false`; no hay desglose de CPU por función, parseo o render ni tamaño exacto del futuro seed. Los long tasks/contadores opcionales no equivalen a CPU consumida. Diagnóstico CPU separado del A/B, si se usa.
