# Referencia aprobada — Funcional

`aprobado-desktop.png` y `aprobado-mobile.png` son capturas de un prototipo HTML
local, no imágenes generadas ni capturas de producción. El owner cerró esta
dirección en chat el2026-10-11 y autorizó aplicarla a /negocios (spec0200).

Variante final: listas verticales en cada plan, Conecta con precio terracota y
fondo cálido, Impulso neutral, sin corazones. Se conservan secciones y storytelling.

El prototipo usaba una marca simplificada, acciones desactivadas y un footer
resumido. La implementación mantiene la marca, CTA y legales reales, y añade
adaptación oscura y navegación por teclado. Esas diferencias son necesarias
para pasar del prototipo a la página real; no implican una nueva filosofía.

La referencia sustituye visualmente a los mockups de barrio conectado usados en 0199. Sus recursos fotográficos se reutilizan. Las aprobaciones y estados antiguos
del helper no acreditan esta implementación ni se han modificado para simularlo.

Filosofía duradera: `../../../DESIGN.md`. La aplicación a otras páginas requiere
revisar su contenido y tareas; estas capturas no obligan a copiar su composición.
