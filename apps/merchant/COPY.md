# Español para comercios de LATAM

El texto de registro, acceso, configuración inicial, tutoriales, panel, errores y correos para comercios usa **tuteo**. La misma voz se aplica a las plantillas predeterminadas que el comercio puede mostrar a sus clientes.

- Usa «puedes», «tienes», «elige», «revisa» y «crea». Evita «podés», «tenés», «elegí», «revisá» y «creá».
- Escribe instrucciones directas y breves. En los errores, indica qué ocurrió y qué puede hacer la persona.
- Prefiere «equipo», «panel» y «persona propietaria» en el texto visible; reserva `staff`, `backoffice` y `owner` para nombres internos.
- Mantén los términos del producto: «local», «sello», «puntos», «premio», «programa de fidelización» y «QR».
- Usa «email» para la dirección y «correo» para la bandeja o el mensaje cuando ayude a distinguirlos. Evita alternarlos sin motivo dentro de una misma pantalla.
- Revisa verbos con pronombre unido: «guárdalo», «regístrate», «únete», «pídele». Un reemplazo de «guardá» por «guarda» no corrige «guardalo».

Las rutas, claves de API y prompts internos conservan sus nombres y redacción técnica. Este criterio aplica al texto que ve una persona.
